# Car Service & Mechanic Hub - Backend

Production Express.js & MongoDB API service.

## Scripts
- `npm run dev`: Start development server with nodemon
- `npm start`: Start production server (`node server.js`)
- `npm run seed`: Seed demo users, categories, services, and mechanics
- `npm run create-admin`: Create or promote admin account

## Environment Variables
See `.env.example` for required variables:
- `PORT`
- `MONGO_URI`
- `JWT_SECRET`
- `CLIENT_URL` / `FRONTEND_URL`
- `EMAIL_USER` / `EMAIL_PASS` (optional)
